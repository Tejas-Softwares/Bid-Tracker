# Tejas Bid Tracker

The bid tracker for Tejas Group: every enquiry and tender from the day it arrives until the order is won, shared by the whole bid team.

- Each person signs in with their own email and password; an admin approves new accounts.
- Bids belong to **Tejash Electrical Projects Pvt. Limited** or **Tejas Electrical Proprietorship Projects**, with separate bid numbers, and every screen can be filtered by company.
- Offers and revisions, **NT (non-tendered) items** that create a new offer revision automatically, client contacts, commercial terms and EMDs, checklist, notes, reports and Excel export.
- An **Activity** log of everything anyone does, with name and email; admins can bring back deleted bids.
- Nightly backups kept for 90 days.

**To put it online, follow [SETUP.md](SETUP.md).**

For development: `npm install`, then `npm run dev` (http://localhost:3000, setup code `dev-setup`) and `npm test`.
